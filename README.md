# Проєкт "Inventarium"

## Функціональність
- ✅ Публічний реєстр інвентарних описів
- ✅ Пошук інвентаря за ключовими словами
- ✅ Картографічне представлення реєстру інвентарів
- ✅ Додавання записів в реєстр інвентарів


## Про проєкт
«Інвентаріум» — це волонтерська ініціатива, спрямована на створення публічного реєстру інвентарних описів маєтків, що стосуються українських земель.

Інвентарні описи — це документи, які фіксували склад і стан маєтків, землю, будівлі, інвентар, населення, обов’язки селян та інші важливі дані. Вони є унікальним джерелом для дослідників історії, істориків локальних громад, краєзнавців та генеалогів

## Інтеграція з системою «Карма» Генеалогічного навігатора

Сайт інтегровано з системою «Карма» Генеалогічного навігатора (https://www.uagenealogy.com).
Користувачі впізнаються за email (поле `login` в API = email у нижньому регістрі).
Сумарний бал користувача (`total`) — це кількість його записів у реєстрі
(підтверджені `records` + неперевірені `records_unverified`).

### Змінні оточення

| Змінна | Призначення |
| --- | --- |
| `KARMA_TOKEN` | Bearer-токен для API «Карми». Видає адмін Навігатора. **Серверний секрет — без префікса `NEXT_PUBLIC_`, не зберігати в коді.** |
| `CRON_SECRET` | Секрет для захисту нічного cron-ендпоінта. Vercel Cron надсилає його як `Authorization: Bearer <CRON_SECRET>`. |

Додайте їх у Project Settings → Environment Variables на Vercel і локально у `.env.local`
(приклад — у `.env.local.example`).

### Сторінка привʼязки акаунта

- URL: **`/karma-link`** (повний: `https://<домен>/karma-link`).
- Це посилання треба передати адміну Навігатора як «посилання на сторінку привʼязки» —
  саме на нього веде кнопка в Навігаторі. Підтримується автопідстановка коду через
  `?code=XXXX` (наприклад, `https://<домен>/karma-link?code=A1B2C3`).
- Сторінка доступна лише залогіненим. Вона не викликає API «Карми» напряму, а проксує
  запит через `POST /api/karma/link` (сервер додає `KARMA_TOKEN` і рахує `total`),
  який далі викликає `POST https://www.uagenealogy.com/api/karma/link-redeem`.

### Нічна синхронізація балів

- Заплановано через **Vercel Cron** (`vercel.json`): щодня о 02:00 UTC викликається
  `GET /api/karma/ingest-cron`.
- Ендпоінт збирає всіх користувачів з email та їхній поточний сумарний бал,
  формує `accounts = [{ login, total }]` і відправляє пачками по ~500 у
  `POST https://www.uagenealogy.com/api/karma/ingest`.
- `total` — це поточний підсумок (не приріст). Бали лише зростають: менший `total`
  нічого не змінює. Email-и зі списку `unknown` — це ще не привʼязані акаунти, це не помилка.
